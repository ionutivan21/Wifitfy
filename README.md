# Wifitfy

Un proiect Python pentru gestionarea și optimizarea rețelelor WiFi.

## 🎯 Descriere

Wifitfy este o aplicație utilă pentru administrarea, monitorizarea și optimizarea conexiunilor WiFi. Aceasta oferă instrumente pentru a analiza și îmbunătăți performanța rețelei wireless.

## 🚀 Caracteristici

- 📊 Monitorizarea performanței rețelei WiFi
- 🔍 Analiza semnalului și calității conexiunii
- ⚙️ Optimizarea configurației rețelei
- 📱 Interfață ușor de utilizat
- 🛡️ Suport pentru gestionarea securității

## 💻 Cerințe Sistem

- Python 3.7+
- Dependențe listate în `requirements.txt`

## 📦 Instalare

### 1. Clonarea repositoriului
```bash
git clone https://github.com/ionutivan21/Wifitfy.git
cd Wifitfy
```

### 2. Instalarea dependențelor
```bash
pip install -r requirements.txt
```

### 3. Pornirea aplicației
```bash
python main.py
```

## 🔧 Utilizare

```bash
# Exemplu de utilizare de bază
python wifitfy.py --scan

# Vezi mai multe opțiuni
python wifitfy.py --help
```
